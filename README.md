# GrokCode

Desktop coding assistant. Left sidebar of projects, multiple Grok chats at once.

## Run

1. `npm install`
2. Sign in once in a terminal: `grok login` (SuperGrok). No separate API key needed.
3. `npm run dev`

Chats are real Grok Build sessions. Sessions already on disk for a folder show up in that project.

## What works now

- Native desktop window
- Projects, optional local folder
- Multiple chats per project
- Concurrent streams: switch tabs without cancelling
- Grok 4.6 by default
